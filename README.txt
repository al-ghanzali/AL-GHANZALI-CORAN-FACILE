CORAN FACILE — VERSION PROTOTYPE

Contenu :
- Site web adaptatif français/arabe
- Échantillon : Al-Fatiha, Al-Ikhlas, Al-Falaq et An-Nas
- Sens français pédagogique, translittération et synthèses explicatives
- Progression mémorisée localement sur l'appareil
- PWA / cache hors connexion après première visite en ligne via HTTPS
- Lien vers Quran.com pour écouter en ligne

Limites connues :
- Ce prototype ne contient pas encore les 114 sourates.
- Aucun fichier audio n'est embarqué : l'écoute en ligne demande Internet.
- Les synthèses sont originales et ne sont pas des citations littérales d'Ibn Kathir. Obtenir et vérifier les droits d'une édition française avant d'intégrer un tafsir complet.
- Les traductions françaises sont des rendus pédagogiques à faire relire par une personne compétente avant diffusion publique.
- Le cache hors connexion nécessite d'abord une visite du site publié en HTTPS. Pour iPhone, ouvrir le site dans Safari puis Partager > Sur l'écran d'accueil. Pour Android, utiliser le menu du navigateur > Installer/Ajouter à l'écran d'accueil.

HÉBERGEMENT GRATUIT POSSIBLE : GitHub Pages, Cloudflare Pages ou Netlify (offres gratuites sujettes à leurs conditions). Aucun frais obligatoire pour un prototype. Une publication native sur App Store peut nécessiter un compte développeur payant; une PWA évite cela au départ.

Pour tester localement : ouvrir index.html. Les fonctions hors connexion/PWA ne fonctionnent pleinement que via localhost ou HTTPS.
